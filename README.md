# Sales MIS Dashboard (MySQL + Power BI)

## Problem Statement
Built an automated sales reporting system to track revenue, regional
performance, and product trends for a retail dataset, replacing manual
report generation with SQL-driven summaries and a Power BI dashboard.

## Tools Used
- MySQL (data modeling, stored procedures, window functions)
- Power BI (dashboard, DAX)
- Dataset: [Superstore Dataset –https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Project Status
🚧 In progress — currently on [Phase 1:schema design]

## Approach
1. Staged raw data in MySQL
2. Cleaned and modeled into a relational schema (`customers`, `products`, `regions`, `orders`)
3. Built SQL analysis layer (MoM/YoY growth, top-N products, regional profit analysis)
4. Built Power BI dashboard connected directly to MySQL
5. Automated report refresh via [stored procedures / scheduled event]
